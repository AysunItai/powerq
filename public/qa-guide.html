Before You Start

What this test covers

This test verifies that content in the chat widget is correctly isolated per workspace. You will open the widget for Workspace A and Workspace B, review the conversation list, open conversations, send test messages, and confirm that content does not appear across workspaces.

Important note

Some workspaces may have an empty conversation list. This is not a failure by itself. If a list is empty, continue the test using the message checks (Step 6), which will create visible message content in that workspace.

Please take your time during each step: check conversation names carefully, open a conversation to verify message content, and then repeat after switching workspaces.

Step 3: Review Workspace A

  1. Select Workspace A

    Click the "Workspace A" box. It should visually indicate it is selected.

  2. Open the chat widget

    Click "🚀 Open Chat with Selected Workspace".

  3. Review the conversation list

    Look at the list of conversations shown in the widget.

    📝 Record these details:
    • Write down 1–2 conversation names you can see.
    • If the list is empty, write down: "Workspace A: no conversations visible".
  4. Open one conversation (if available)

    Click a conversation from the list and briefly review the message area. You are verifying you can open and read messages normally in Workspace A.

  5. Close the chat widget

    Click the X button to close the widget before moving to Workspace B.

Step 4: Review Workspace B

  1. Select Workspace B

    Click the "Workspace B" box. It should visually indicate it is selected.

  2. Open the chat widget

    Click "🚀 Open Chat with Selected Workspace".

  3. Review the conversation list

    Look at the list of conversations shown in the widget.

    📝 Record these details:
    • Write down 1–2 conversation names you can see.
    • If the list is empty, write down: "Workspace B: no conversations visible".
  4. Compare against Workspace A
    ✅ Expected

    The conversation names shown in Workspace B should not match the conversation names recorded in Workspace A.

    ❌ Failure

    If you see conversation names from Workspace A while Workspace B is selected, record this as a FAIL.

  5. Open one conversation (if available)

    Click a conversation from the list and briefly review the message area. You are verifying you can open and read messages normally in Workspace B.

  6. Close the chat widget

    Click the X button to close the widget before continuing.

Step 5: Validate Isolation (Primary Test)

This is the primary validation step. It verifies that conversations and messages from one workspace do not appear or remain accessible when another workspace is selected.

⚠️ Important

Perform the checks slowly and carefully. If any content clearly belongs to the other workspace, record it immediately and include the conversation name and what you observed.

Check A → B

  1. Select Workspace B and open the widget

    Open the chat widget while Workspace B is selected.

  2. Review the conversation list

    Compare the visible conversation names to the names you recorded earlier for Workspace A.

  3. Result
    ✅ PASS condition

    No Workspace A conversation names appear while Workspace B is selected.

    ❌ FAIL condition

    Any Workspace A conversation appears in Workspace B.

  4. Close the widget

    Close the chat widget before the next check.

Check B → A

  1. Select Workspace A and open the widget

    Open the chat widget while Workspace A is selected.

  2. Review the conversation list

    Compare the visible conversation names to the names you recorded earlier for Workspace B.

  3. Result
    ✅ PASS condition

    No Workspace B conversation names appear while Workspace A is selected.

    ❌ FAIL condition

    Any Workspace B conversation appears in Workspace A.

Step 6: Message Visibility Check

This step verifies that messages created in one workspace never appear in the other workspace. It also provides a reliable signal even if the conversation list starts empty.

Workspace A Message Check

  1. Select Workspace A and open the widget

    Open the chat widget while Workspace A is selected.

  2. Open any available conversation

    If a conversation is available, open it. If none exist, use any available message input area that allows sending a message.

  3. Send this exact message
    Send the following message exactly: WORKSPACE A – QA MESSAGE CHECK
  4. Confirm the message is visible

    Verify the message appears in the Workspace A chat view.

  5. Close the widget

    Close the chat widget before opening Workspace B.

Workspace B Confirmation

  1. Select Workspace B and open the widget

    Open the chat widget while Workspace B is selected.

  2. Search visually for the Workspace A message

    Review conversations and messages.

    ✅ PASS condition

    The message WORKSPACE A – QA MESSAGE CHECK does not appear anywhere in Workspace B.

    ❌ FAIL condition

    The message WORKSPACE A – QA MESSAGE CHECK appears in Workspace B.

Repeat in the opposite direction

  1. In Workspace B, send this exact message
    Send the following message exactly: WORKSPACE B – QA MESSAGE CHECK
  2. Open Workspace A and confirm it does not appear
    ✅ PASS condition

    The message WORKSPACE B – QA MESSAGE CHECK does not appear anywhere in Workspace A.

    ❌ FAIL condition

    The message WORKSPACE B – QA MESSAGE CHECK appears in Workspace A.

Expected Results

✅ PASS

Record PASS if all of the following are true:

  • Workspace A shows only Workspace A conversations and messages.
  • Workspace B shows only Workspace B conversations and messages.
  • Messages sent in one workspace never appear in the other workspace.
  • Switching between workspaces does not reveal previous content from the other workspace.

Use this wording: PASS — Workspace isolation verified

❌ FAIL

Record FAIL if any of the following occur:

  • Conversations from Workspace A appear while Workspace B is selected.
  • Conversations from Workspace B appear while Workspace A is selected.
  • Messages from one workspace are visible in the other workspace.
  • Previously viewed content remains accessible after switching workspaces.

Use this wording: FAIL — Cross-workspace content visible

What to include in a FAIL report
  • Which workspace was selected (A or B)
  • The conversation name (if visible)
  • The message text (if visible)
  • When it happened (on open / after switching / after sending a message)

QA Checklist (Please Complete)

Use this checklist while testing. Check each item as you complete it.

Workspace A

  • Opened chat for Workspace A
  • Reviewed conversation list and wrote down 1–2 names (or noted empty)
  • Opened one conversation (if available) and verified messages load
  • Sent WORKSPACE A – QA MESSAGE CHECK and confirmed it appears

Workspace B

  • Opened chat for Workspace B
  • Reviewed conversation list and wrote down 1–2 names (or noted empty)
  • Opened one conversation (if available) and verified messages load
  • Sent WORKSPACE B – QA MESSAGE CHECK and confirmed it appears

Isolation Checks

  • While in Workspace B, confirmed no Workspace A conversation names appear
  • While in Workspace A, confirmed no Workspace B conversation names appear
  • Confirmed WORKSPACE A – QA MESSAGE CHECK does not appear in Workspace B
  • Confirmed WORKSPACE B – QA MESSAGE CHECK does not appear in Workspace A

🔧 Troubleshooting

"No workspaces configured" error?

Result:

Record this as Blocked and notify the developer. The environment may need configuration.

Can't see the two workspace boxes?

Actions to try:
  • Confirm you are logged in (Step 2)
  • Refresh the page
  • Return to the home page and re-open the QA test page

Chat doesn't open?

Actions to try:
  • Confirm you selected a workspace box first
  • Wait a few seconds and try again
  • If the issue continues, record as Blocked and include what you see on screen

📋 What to Report

✅ PASS report
  • Workspace A and Workspace B both open successfully
  • Each workspace shows only its own conversations and messages
  • No cross-workspace conversations or messages are visible

Use: PASS — Workspace isolation verified

❌ FAIL report
  • Cross-workspace conversation names appear
  • Cross-workspace messages appear
  • Content remains accessible after switching workspaces
  • Any unexpected behavior that exposes the other workspace

Use: FAIL — Cross-workspace content visible

BLOCKED report

If you cannot complete the test due to setup issues (cannot log in, chat does not open, missing workspaces), record as Blocked and include a short description of what you see.
