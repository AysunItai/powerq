🧪 QA Testing Guide

Simple step-by-step instructions for testing workspace isolation feature

Step 1: Open the Testing Page

Go to the QA testing page:

📍 Testing Page URL: http://localhost:3000/qa-test.html

Or click the "🧪 QA Test" link in the navigation menu.

Go to QA Test Page →

Step 2: Login (If Needed)

If you see a BIG YELLOW BOX:

⚠️ YOU NEED TO LOGIN FIRST!
  1. Click the big blue button that says "👉 CLICK HERE TO LOGIN 👈"
  2. Use these credentials:
    • Email: john@example.com
    • Password: password123
  3. After logging in, you'll be redirected back to the QA test page

If you see TWO BIG BOXES (Workspace A and Workspace B):

✅ YOU'RE READY TO TEST!

You're already logged in. Proceed to Step 3.

Step 3: Test Workspace A

  1. Click on the "Workspace A" box

    The box will turn purple/blue when selected

  2. Click the "🚀 Open Chat with Selected Workspace" button

    This will open the chat widget

  3. A chat window will open

    The chat window appears in the bottom-right corner of your screen

  4. Look at the topics/conversations list

    You should see a list of topics or conversations in the chat window

    📝 IMPORTANT: Write down 2-3 topic names you see (e.g., "Support Ticket #123", "General Chat", "Question about X"). You'll need these for Step 5!
  5. If you don't see any topics:

    Send a test message in the chat - this will create a topic. Then write down the topic name.

Step 4: Test Workspace B

  1. Close the Workspace A chat window

    Click the X button to close the current chat

  2. Click on the "Workspace B" box

    The box will turn purple/blue when selected

  3. Click "🚀 Open Chat with Selected Workspace" again

    A new chat window will open for Workspace B

  4. Look at the topics list in Workspace B

    Check the list of topics/conversations you see

  5. Compare with Workspace A topics
    ✅ CORRECT: The topics in Workspace B should be DIFFERENT from the topics you saw in Workspace A. If you see the same topics, that's a problem!
    ❌ PROBLEM: If you see topics from Workspace A in Workspace B's list, that means isolation is NOT working. Report this as a FAIL.
  6. If you don't see any topics in Workspace B:

    Send a test message to create a topic. Make sure it's different from Workspace A topics.

Step 5: Test Isolation (403 Error) - THE MOST IMPORTANT TEST!

This test verifies that workspaces are properly isolated and users can't access topics from other workspaces.

⚠️ IMPORTANT:

You need to have topics/messages in BOTH workspaces to test this. If you don't have topics yet, create some first!

How to Test Workspace Isolation:

💡 Understanding How It Works:

Think of it like this:

  • Workspace = A company/organization (like "Starbucks" or "Amazon")
  • Topic = A conversation/chat thread (like "Support Ticket #123" or "General Discussion")
  • Message = Individual messages inside a topic

Important: Each topic "belongs" to one workspace. When you're logged into Workspace A, you should ONLY see topics that belong to Workspace A. You should NOT see topics from Workspace B.

📝 Step-by-Step Instructions:

Follow these steps. You will send test messages and check if topics from one workspace appear in the other workspace.

  1. Step 1: Create test topics in Workspace A (with unique names you can remember):
    • Click "Workspace A" box (it turns blue/purple)
    • Click "🚀 Open Chat with Selected Workspace"
    • In the chat window, send these messages (one at a time):
      Send these messages in Workspace A:
      1. "WORKSPACE A - TEST TOPIC 1"
      2. "WORKSPACE A - TEST TOPIC 2"
      3. "WORKSPACE A - TEST TOPIC 3"
    • Look at the topic list - you should see topics with names like "WORKSPACE A - TEST TOPIC 1"
    • Write down on paper: "Workspace A topics: [list the topic names you see]"
    • Close the chat window (click X)
  2. Step 2: Create test topics in Workspace B (with DIFFERENT names):
    • Click "Workspace B" box (it turns blue/purple)
    • Click "🚀 Open Chat with Selected Workspace"
    • CRITICAL CHECK #1: Look at the topic list. Do you see ANY topics that say "WORKSPACE A" in the name?
      ❌ IF YES: You see "WORKSPACE A - TEST TOPIC 1" or similar = FAIL! Report this immediately. Isolation is broken.
      ✅ IF NO: You don't see any "WORKSPACE A" topics = GOOD! Isolation is working so far.
    • Now send these messages in Workspace B:
      Send these messages in Workspace B:
      1. "WORKSPACE B - TEST TOPIC 1"
      2. "WORKSPACE B - TEST TOPIC 2"
      3. "WORKSPACE B - TEST TOPIC 3"
    • Look at the topic list - you should see topics with names like "WORKSPACE B - TEST TOPIC 1"
    • Write down on paper: "Workspace B topics: [list the topic names you see]"
    • Close the chat window
  3. Step 3: Test Isolation - Can you see Workspace A topics from Workspace B?
    • Make sure you're in Workspace B (box should be blue/purple)
    • Open the chat window
    • Look at the topic list carefully
    • CRITICAL CHECK #2: Can you see ANY topic that says "WORKSPACE A" in the name?
      ✅ CORRECT (PASS): You should NOT see any "WORKSPACE A" topics. You should ONLY see "WORKSPACE B" topics. This means isolation is working!
      ❌ WRONG (FAIL): If you can see "WORKSPACE A - TEST TOPIC 1" or similar, that's a FAIL. Report this immediately.
  4. Step 4: Test Isolation - Can you see Workspace B topics from Workspace A?
    • Close Workspace B chat
    • Click "Workspace A" box
    • Open the chat window
    • Look at the topic list carefully
    • CRITICAL CHECK #3: Can you see ANY topic that says "WORKSPACE B" in the name?
      ✅ CORRECT (PASS): You should NOT see any "WORKSPACE B" topics. You should ONLY see "WORKSPACE A" topics.
      ❌ WRONG (FAIL): If you can see "WORKSPACE B - TEST TOPIC 1" or similar, that's a FAIL. Report this immediately.
  5. Step 5: Test Message Content Isolation (BONUS TEST):
    • In Workspace A, click on a topic (like "WORKSPACE A - TEST TOPIC 1")
    • Read the messages - they should say "WORKSPACE A - TEST TOPIC 1"
    • Close Workspace A chat
    • Open Workspace B chat
    • CRITICAL CHECK #4: Can you see messages that say "WORKSPACE A" anywhere?
      ✅ CORRECT: You should NOT see any messages with "WORKSPACE A" text. You should only see "WORKSPACE B" messages.
      ❌ WRONG: If you can read messages that say "WORKSPACE A", that's a FAIL.
✅ PASS - Report these results:
  • ✅ In Workspace B, you do NOT see any topics with "WORKSPACE A" in the name
  • ✅ In Workspace A, you do NOT see any topics with "WORKSPACE B" in the name
  • ✅ Each workspace shows ONLY its own topics (A shows only A topics, B shows only B topics)
  • ✅ You cannot read messages from the other workspace

If all checks above are ✅, write: "PASS - Workspace isolation is working correctly"

❌ FAIL - Report these problems immediately:
  • ❌ In Workspace B, you CAN see topics with "WORKSPACE A" in the name
  • ❌ In Workspace A, you CAN see topics with "WORKSPACE B" in the name
  • ❌ You can open and read messages from topics in the wrong workspace
  • ❌ Topics from one workspace appear in the other workspace's list

If ANY check above is ❌, write: "FAIL - Workspace isolation is broken" and describe what you saw

💡 REMEMBER - You Don't Need to See Topic IDs!

You don't need developer tools, database access, or any technical knowledge. Just:

  • ✅ Look at the topic names you can see in the chat window
  • ✅ Use simple test messages like "WORKSPACE A - TEST TOPIC 1" so you can easily identify them
  • ✅ Check if topics from one workspace appear in the other workspace's list
  • ✅ That's it! No technical knowledge needed!
⚠️ Remember:
  • Each topic belongs to ONE workspace only
  • Each message belongs to ONE topic only
  • When you're in Workspace A, you should ONLY see topics and messages from Workspace A
  • When you're in Workspace B, you should ONLY see topics and messages from Workspace B
  • If you can see or access topics/messages from the wrong workspace, that's a FAIL ❌

🔧 Troubleshooting

"No workspaces configured" error?

Solution:

Tell the developer - the server needs to be restarted with proper .env file

Can't see the two boxes?

Solutions:
  • Make sure you're logged in (see Step 2)
  • Check the top of the page for a status message
  • Refresh the page

Chat doesn't open?

Solutions:
  • Check the browser console (press F12)
  • Make sure you selected a workspace first (box should be purple/blue)
  • Wait a few seconds and try again

📋 What to Report

✅ PASS - Report these if everything works:
  • Can see both Workspace A and B boxes
  • Can open chat for each workspace
  • Each workspace shows different content
  • Cannot access other workspace (403 error)
❌ FAIL - Report these if something doesn't work:
  • Cannot see workspace boxes
  • Chat doesn't open
  • Can access topics from wrong workspace (no 403 error)
  • Any error messages
